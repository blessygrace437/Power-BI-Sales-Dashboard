# Sales Performance Dashboard using Power BI

## About This Project
This is my third data analytics project where I built
an interactive Sales Dashboard using Power BI as part
of my learning journey in Data Analytics.

## Dataset
- 500 sales records (practice dataset)
- Fields: Region, Category, Product, Sales Rep,
  Units Sold, Price, Total Sales, Profit

## What I Built
- KPI Cards → Total Sales, Profit, Units, Orders
- Bar Chart → Sales by Region
- Donut Chart → Sales by Category
- Line Chart → Monthly Sales Trend 2024
- Column Chart → Profit by Sales Rep

## Tools Used
- Power BI Desktop
- Microsoft Excel (Data Source)
- Power Query (Data Cleaning)

## What I Learned
- Importing Excel data into Power BI
- Using Power Query for data cleaning
- Creating KPI cards and visualizations
- Building interactive business dashboard
